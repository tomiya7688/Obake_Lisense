「かどか（Kadoka）」と「まる（maru）」のおばけ素材を公開するリポジトリです。

## ライセンスの正本

**Obake Character License の正本は、このリポジトリの日本語版 [`LICENSE.md`](LICENSE.md) です。**

- 日本語・正本: [`LICENSE.md`](LICENSE.md)
- English translation: [`LICENSE.en.md`](LICENSE.en.md)

翻訳版との間に解釈上の相違がある場合は、日本語版が優先されます。

「おばけの住処」の公式世界設定は別リポジトリ [`tomiya7688/chatgpt-obakenosumika`](https://github.com/tomiya7688/chatgpt-obakenosumika) で管理していますが、**ライセンスの正本は本リポジトリです。**

## できること

[Obake Character License v1.1](LICENSE.md) の条件に従う限り、商用・非商用を問わず、素材を使えます。

- 改変、二次創作、再配布
- ゲーム、アプリ、Webサイト、動画、配信、書籍、印刷物への利用
- 製品・グッズへの利用、およびそれらを含む有料作品・製品の販売

公式素材をそのまま素材集として再販売したり、公式と誤認させたり、おばけそのものの独占権を主張したりすることはできません。詳しい利用条件は、必ず [ライセンス本文](LICENSE.md) を確認してください。

## 素材

素材は [Assets](Assets) にあります。

| キャラクター | 公開ファイル |
| --- | --- |
| かどか（Kadoka） | `Kadoka.png`、`Kadoka_original.png`、`Kadoka.ink`、`Kadoka.gif` |
| まる（maru） | `Maru.png`、`Maru_original.png`、`Maru.ink`、`Maru.gif` |

- `.png` は利用用の画像です。
- `*_original.png` は原本画像です。
- `.ink` は Inkscape で編集できる元データです。
- `.gif` はアニメーション画像です。

## クレジットと再配布

クレジット表記は必須ではありません。表記できる場合は、素材名またはこのリポジトリへのリンクを付けてください。

素材や改変物を再配布する場合は、利用者が [ライセンス本文](LICENSE.md) を確認できるようにすることを推奨します。
