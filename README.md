# Obake_Lisense

このリポジトリは、**おばけ「かどか（Kadoka）」と「まる（maru）」の公式素材・設定・ライセンスを公開するためのリポジトリ**です。

ここで扱うライセンスは、Kadokaというブランドそのものの利用規約ではなく、**おばけたちというキャラクターそのものを、どのように利用・改変・登場させてよいか**を定めるものです。

## 基本方針

おばけたちは、いろいろな作品や製品の中に自由に住み着いてほしいと考えています。

そのため、公式画像をそのまま使用する必要はありません。

**かどか・まるだと分かる範囲であれば、見た目を改変して構いません。**

たとえば、次のような変更を想定しています。

- 絵柄の変更
- デフォルメ
- ドット絵化
- 3D化
- 表情やポーズの変更
- 衣装や小物の追加
- 色味や陰影の変更
- UIアイコン向けの簡略化
- 製品や作品に合わせたデザイン変更

完全に同じ絵を使うことよりも、**見ればおばけたちだと分かること**を重視します。

## 利用について

おばけたちは、原則として広く利用できるようにする方針です。

想定している利用例には、次のようなものがあります。

- ゲームへの登場
- ソフトウェアへの登場
- Webサイトへの掲載
- 動画・配信での利用
- イラストや漫画などの二次創作
- 印刷物への掲載
- ハードウェアや製品への印刷・刻印
- 有料作品・有料製品への登場
- 改変したおばけ素材の利用

**有料の作品や製品の中に、おばけたちを登場させること自体は問題ありません。**

一方で、おばけたちそのものを囲い込み、他の人が利用できない存在として独占することは、このプロジェクトの考え方に反します。

## おばけは無料であり続けます

公式のおばけそのものを、有料でなければ利用・閲覧できない存在にする予定はありません。

おばけを利用した作品や製品で利益を得ることと、**おばけそのものを有料化・独占すること**は別のものとして扱います。

たとえば、以下のような利用は想定しています。

- 有料ゲームのNPCとしておばけを登場させる
- 販売する製品におばけを描く
- 有料アプリのUIやAbout画面におばけを登場させる

一方で、第三者がおばけそのものについて独占的な権利を主張したり、他の人のおばけ利用を妨げたりすることは認めない方針です。

## 公式と非公式

おばけを利用・改変したからといって、その作品や製品が自動的に公式になるわけではありません。

**自由におばけを使うこと**と、**公式作品・公式製品を名乗ること**は別として扱います。
